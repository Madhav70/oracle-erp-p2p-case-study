# P2P Analysis Outputs & Data Artifacts

This directory contains analytical outputs, summary tables, and visualizations generated by `p2p_analysis.py` using synthetic baseline data generated by `generate_sample_data.py`.

## Contents

1. **`p2p_summary_metrics.json`**:
   Comprehensive JSON document detailing financial totals, transaction volumes, discrepancy rates, exception breakdowns, and cycle times. Used by the interactive dashboard.

2. **`spend_by_supplier.csv`**:
   Breakdown of total committed spend, invoice counts, paid amounts, and invoice exception rates per supplier.

3. **`spend_by_category.csv`**:
   Procurement spend segmented across operational categories (Raw Materials, MRO & Tooling, Packaging, Facilities & Services, Logistics, IT).

4. **`exception_analysis.csv`**:
   Detailed classification of invoice match statuses (Clean Match, Price Variance Hold, Missing Receipt Hold, Quantity Variance Hold) along with associated variance amounts and simulated resolutions.

5. **`cycle_times.csv`**:
   Stage-by-stage cycle times comparing current simulated performance against To-Be target service level agreements (SLAs).

6. **Charts (`.png`)**:
   - `chart_spend_by_category.png`: Horizontal bar chart of committed spend by category.
   - `chart_monthly_spend.png`: Monthly trend of PO issuance volume (Jan - Jun 2026).
   - `chart_exception_breakdown.png`: Donut chart showing invoice matching status distribution.
   - `chart_cycle_times.png`: Bar comparison between simulated current state and target ERP SLAs.

*Note: All data and metrics are synthetic and represent a fictional case study for Northstar Manufacturing Ltd.*
